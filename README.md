# Petition App

Цей проект є Laravel застосунком з використанням Inertia.js та React.

## Вимоги

Перед початком роботи переконайтеся, що у вас встановлено:
- PHP 8.4 або новіше
- Composer
- Node.js та NPM

## Встановлення та налаштування

У проекті налаштований зручний скрипт для швидкого розгортання.

1. **Клонуйте репозиторій** та перейдіть у папку проекту.

2. **Запустіть налаштування**:
   Ця команда встановить PHP та JS залежності, створить файл `.env`, згенерує ключ додатку, запустить міграції бази даних та збере фронтенд.
   ```bash
   composer run setup
   ```

   > Якщо ви бажаєте виконати кроки вручну:
   > ```bash
   > composer install
   > cp .env.example .env
   > php artisan key:generate
   > php artisan migrate
   > npm install
   > npm run build
   > ```

## Запуск проекту

Для розробки найзручніше використовувати команду `dev`, яка одночасно запускає локальний сервер, обробку черг та Vite (для гарячої заміни фронтенду).

```bash
composer run dev
```

Після цього додаток буде доступний за адресою: [http://localhost:8000](http://localhost:8000)
